# BrainServe Connect — Client Demo

Extract this ZIP, then run **START_DEMO.cmd** on Windows or `node demo/serve.mjs` on macOS/Linux. Node.js 22.13+ is required. Open **http://127.0.0.1:4180**. No npm installation or database is needed.

Read [CLIENT_DEMO.md](CLIENT_DEMO.md) for the walkthrough and [DEMO_VERIFICATION.md](DEMO_VERIFICATION.md) for checks and limitations.

This is a browser-only demo with sample data, not a production server.
